# Project

Urban Drone Delivery Simulator

Goal:

Build a full-stack application capable of simulating urban package deliveries using autonomous drones.

Current stack:

- React
- ASP.NET Core 8
- Entity Framework Core
- MySQL
- Docker Compose

Architecture:

- MVC
- Services contain business rules.
- Controllers remain thin.
- React consumes the REST API.

Main features:

- Drone management
- Order management
- Delivery allocation
- Route calculation
- Battery simulation
- Dashboard
- Automated tests

Development order:

1. Infrastructure
2. Backend
3. Frontend
4. Tests
5. Documentation
